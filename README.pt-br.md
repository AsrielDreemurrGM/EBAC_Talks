<h2>Visão Geral do Projeto</h2>
<p>
  EBAC Tech Talks é uma landing page de um evento fictício de tecnologia, criada para praticar
  <strong> Parcel</strong>, <strong>SCSS</strong> e <strong>JavaScript</strong>.
  O projeto inclui um contador regressivo, design responsivo e animações aplicadas com
  <code> AOS (Animate On Scroll)</code>.
</p>
<h2>Demo Online</h2>
<p>
  🔗 Hospedagem na Vercel:
  <a href="https://ebac-talks-one-self.vercel.app" target="_blank"> Visualizar no Vercel</a>
</p>
<h2>Funcionalidades</h2>
<ul>
  <li>Contador regressivo dinâmico até a data do evento.</li>
  <li>Design responsivo com seções para Front-end, UI/UX, Data Science e Back-end.</li>
  <li>Animações ao rolar a página utilizando <code>AOS</code>.</li>
  <li>Estrutura SCSS organizada com variáveis, componentes e layouts.</li>
  <li>Otimização de imagens com <code>sharp</code> para melhor desempenho.</li>
</ul>
<h2>Tecnologias Utilizadas</h2>
<ul>
  <li>HTML5</li>
  <li>SCSS / SASS</li>
  <li>JavaScript</li>
  <li>Parcel (Bundler)</li>
  <li>Sharp (Otimização de imagens)</li>
  <li>AOS (Animate On Scroll)</li>
</ul>
<h2>Como Usar</h2>
<ol>
  <li>Clone o repositório.</li>
  <li>Execute <code>npm install</code> para instalar as dependências.</li>
  <li>Inicie o ambiente de desenvolvimento com <code>npm run dev</code>.</li>
  <li>Gere a versão de produção com <code>npm run build</code>.</li>
</ol>
