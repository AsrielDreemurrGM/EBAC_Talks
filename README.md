<h2>Project Overview</h2>
<p>
  EBAC Tech Talks is a fictitious technology event landing page built to practice
  <strong> Parcel</strong>, <strong>SCSS</strong>, and <strong>JavaScript</strong>.
  It features a countdown timer, responsive design, and animations powered by
  <code> AOS (Animate On Scroll)</code>.
</p>
<h2>Live Demo</h2>
<p>
  🔗 Vercel Hosting:
  <a href="https://ebac-talks-one-self.vercel.app" target="_blank"> View on Vercel</a>
</p>
<h2>Features</h2>
<ul>
  <li>Countdown timer dynamically updates until the event date.</li>
  <li>Responsive design with sections for Front-end, UI/UX, Data Science, and Back-end.</li>
  <li>Animations triggered on scroll using <code>AOS</code>.</li>
  <li>Organized SCSS structure with variables, components, and layout partials.</li>
  <li>Image optimization with <code>sharp</code> for faster performance.</li>
</ul>
<h2>Technologies Used</h2>
<ul>
  <li>HTML5</li>
  <li>SCSS / SASS</li>
  <li>JavaScript</li>
  <li>Parcel (Bundler)</li>
  <li>Sharp (Image optimization)</li>
  <li>AOS (Animate On Scroll)</li>
</ul>
<h2>Usage</h2>
<ol>
  <li>Clone the repository.</li>
  <li>Run <code>npm install</code> to install dependencies.</li>
  <li>Start development with <code>npm run dev</code>.</li>
  <li>Build for production with <code>npm run build</code>.</li>
</ol>
